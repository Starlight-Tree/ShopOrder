# 0001 世界観は既存の資料を正とし、通貨はルミにする

- 状態: 決定
- 日付と決めた人: 2026-11-21（ユーザー）

## 背景
ユーザーの依頼は「オアシス珈琲という店の、商品オーダー＆宅配アプリ。惑星ザーハードの店舗の世界観」。オアシス珈琲は、DocuNavi の資料群（`evals/corpora/cafe/`）にすでに設定がある（12 店・4 エリア・看板商品・モバイルオーダー・ポイント制度）。ただし、その資料のポイント制度の金額は「円」で書かれ、JobNavi の通貨は「ルミ」で、食い違っていた。飲み物の価格と、宅配の設定は、資料に無い。

## 決定
- 店・地名・店舗一覧・沿革・サービスは、既存の資料を正とする。作り話で上書きしない。内容は [world.md](../world.md) に、出典つきで写す。
- 通貨は**ルミ**。金額は整数（小数なし）で持つ。資料の「円」は、ルミに読み替える（ポイントは「会計 100 ルミごとに 1 ポイント」）。
- 資料に無い設定（メニュー・価格・宅配）は、このアプリのために**新設**する。world.md で「新設」と区別し、決めたら足す。
- 決済・配達は、架空の世界の中で完結する模擬を既定にする。本物の事業者へ切り替える口（決済・配達・通知のインターフェース）は残す。

## 結果と限界
- 既存の資料（DocuNavi の PDF とその評価）は変えない。DocuNavi の資料が「円」のままである食い違いは、そちらでは直していない（未対応）。
- 日本の法令（特定商取引法・軽減税率・インボイスなど）は、世界観が架空のため適用の対象外。実在の店へ切り替えるときの論点として、別に扱う。
