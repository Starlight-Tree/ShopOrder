```
# NNNN 題（決めたことを 1 文で）

- 状態: 提案 / 決定 / 実装済み / 置き換え（NNNN）
- 日付と決めた人: YYYY-MM-DD（ユーザー / 私の提案をユーザーが承認）

## 背景
## 決定
## 結果と限界
（確認していないことは「未確認」。数字には日付と測り方）
## 出典
```
