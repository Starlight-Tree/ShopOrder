## 並べ方の理由

- 注文の骨（P1）を先に通す。宅配（P2）とチャット（P3）は、同じカート・注文・在庫の上に載るので、骨が揺れる前に積まない。
- チャットは、画面の注文が動いてから。同じ API を呼ぶだけにして、チャット専用の抜け道を作らない。
- 分析（P4）は、ダミーの履歴を seed で入れれば、P1〜P3 と並行して作れる（読み取り専用）。
